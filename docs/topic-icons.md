# Topic icons

All 50 current database categories have a dedicated emoji. Icons follow the stored category name, so English and Ukrainian use the same visual cues. The category label remains the accessible name; decorative icons are hidden from screen readers.

Related topics use distinct cues: the whole body, a body part, and an organ; walking, a tram, and a transit stop; a clock, an alarm, and sunrise. Abstract grammar topics use visual associations: sparkle for describing qualities, speed for how actions happen, puzzle pieces for grammar, people for pronouns, arrows for relative positions, and a runner for verbs.
